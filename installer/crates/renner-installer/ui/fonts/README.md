# Fonts embedded in the installer

The plain Arch ISO has no desktop fonts, so the installer embeds its own.

| File | Source | Licence | SHA256 |
| --- | --- | --- | --- |
| `Inter-Regular.ttf` | Inter 4.1, `extras/ttf/` in https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip | SIL OFL 1.1 (`Inter-LICENSE.txt`) | `40d692fce188e4471e2b3cba937be967878f631ad3ebbbdcd587687c7ebe0c82` |
| `Inter-SemiBold.ttf` | same | SIL OFL 1.1 | `78a843fade9d4612a5567302fb595b56976eb5fcebf4fea5a5912d638bafcde3` |
| `Inter-Bold.ttf` | same | SIL OFL 1.1 | `288316099b1e0a47a4716d159098005eef7c0066921f34e3200393dbdb01947f` |

Display text uses Inter Bold, like the renner.dev launcher (`theme.json`:
display font Inter). The website's Satoshi is not bundled: its ITF Free Font
License text is not in any of our repos, so it cannot be shipped with proper
provenance yet.

`../images/dot-grid.png` is generated by us (a 26 px tile with one dot,
rgba(148,163,184,.16), the renner.dev hero dot grid); no third-party content.
